PRIVACY POLICY

Andromeda, Ho! · Gadolinium Games · Last updated 21 October 2026

This policy tells you what data the game Andromeda, Ho! (Android package com.gadoliniumgames.andromedaho) collects, why we collect it, and how you can control it. "We" means Gadolinium Games.

SUMMARY

  • The game does not show ads and does not sell your data.
  • The game does not ask for your name, email, contacts, location or account.
  • The game sends playtest data to us only after you agree and type a participant code. If you do not agree, the game keeps this data on your device only.
  • The game uses the microphone only when you tap Record Feedback.

DATA THAT WE COLLECT

When you agree to send playtest data, the game sends these items to us:

  • Participant code. The code that you type in the consent dialog. We give each tester a code. The code does not contain your name. Why: to know which data belongs to the same tester, and to block data from unknown senders.
  • Gameplay data. Runs, rooms, choices, weapons, upgrades, damage, time played, results. Why: to balance and improve the game.
  • Device and build data. Operating system and version, device model, language setting, game version, frame rate and performance numbers. Why: to find problems that occur only on some devices.
  • Diagnostics. Game warning and error messages, with the game state at that time. Why: to find and fix bugs and crashes.
  • Voice feedback (optional). An audio recording that you make and send, a screenshot of the game screen at that time, and the game state. Why: to hear your feedback about the game.

The screenshot shows only the game screen. It does not show other apps or your photos.

MICROPHONE

The game asks for microphone permission the first time that you tap Record in the Record Feedback dialog. The game records only while you record. You can listen to the recording, discard it, or send it. If you refuse the permission, the rest of the game operates normally.

HOW WE KEEP AND SEND THE DATA

  • The game sends data over an encrypted (HTTPS) connection.
  • We keep the data in private cloud storage from Cloudflare (Cloudflare R2). Cloudflare keeps the data for us and does not use it for its own purposes.
  • Only the Gadolinium Games team can access the data.
  • We do not share the data with other companies.

Google Play also collects some data when you install the game, for example to deliver updates. The Google Privacy Policy applies to that data.

HOW LONG WE KEEP THE DATA

We keep playtest data and voice recordings only for the playtest. We delete them not later than 12 months after the playtest ends.

YOUR CHOICES

  • Stop sending data: Settings → Playtest Data → turn off uploads. The game then stops sending data.
  • Delete your data: Send an email to the address below with your participant code. We will delete all data for that code within 30 days.
  • Delete data on your device: Uninstall the game, or clear its app data in Android Settings.

THIS WEBSITE

This website does not use cookies, analytics or trackers, and it loads no content from other companies. The site host (GitHub Pages) can record technical data, such as IP addresses, in its server logs.

CHILDREN

This game is not for children younger than 13. We do not knowingly collect data from children younger than 13. If you think that a child sent us data, contact us and we will delete it.

CHANGES TO THIS POLICY

If we change this policy, we will update this page and the "Last updated" date.
